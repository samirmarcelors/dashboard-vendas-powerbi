# 📊 Dashboard de Vendas — Power BI

## 📌 Sobre o projeto

Este projeto apresenta um dashboard desenvolvido no **Power BI** com o objetivo de analisar o desempenho de vendas e transformar dados comerciais em informações úteis para tomada de decisão.

O dashboard permite analisar indicadores de vendas por produtos, vendedores e lojas, facilitando a identificação de tendências e oportunidades de negócio.

## 🎯 Objetivos

* Analisar o desempenho geral das vendas;
* Acompanhar os principais indicadores comerciais;
* Identificar os produtos com melhor desempenho;
* Comparar o desempenho dos vendedores;
* Analisar os resultados por loja;
* Facilitar a tomada de decisões através de visualizações interativas.

## 📦 Produtos analisados

Entre os produtos presentes na análise estão:

* 📱 Smartphones
* 📺 Smart TVs
* 💻 Notebooks

## 📊 Principais análises

O dashboard apresenta informações como:

* Total de vendas;
* Quantidade de produtos vendidos;
* Desempenho por produto;
* Desempenho por vendedor;
* Desempenho por loja;
* Comparativos e indicadores de desempenho;
* Filtros interativos para exploração dos dados.

## 🛠️ Tecnologias utilizadas

* **Power BI**
* **Power Query**
* **DAX**
* **Modelagem de dados**
* **Visualização de dados**

## 🧩 Modelagem

Foi utilizada uma estrutura de dados organizada para possibilitar análises eficientes e criação de medidas e indicadores no Power BI.

As medidas foram desenvolvidas utilizando **DAX**, enquanto o tratamento e preparação dos dados foram realizados através do **Power Query**.
